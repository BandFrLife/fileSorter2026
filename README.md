# fileSorter2026

2026 Oop project. for a file sorter in Linux.

Contributers: Alex Kunzler, Brian Kendrick, Parker Stacy

Class: CSCI 375, Object Oriented Programming and Design Patterns

[D2L link to final project page](https://d2l.coloradomesa.edu/d2l/le/content/267023/Home)

---

### Prerequisites

**Create imgs from uml:** java plantuml

---

### Quick Start

```bash
- `$ make run`  # Runs the file sorter program
```

#### Help
```bash
- `$ make `
# or
- `$ make help `
```

#### Dev env
```bash
- `$ make docker`  # setup and run in container
- `$ make create-random-files`  # add random files to directories for tests
```

Diagrams (img):
```
From root:
- `$ make create-uml`     Creates .png output of diagram
```
